## 상태 표기 범례

설계 문서 전반에서 모든 기술 선택에는 다음 상태가 붙습니다.

| 표기 | 의미 |
|---|---|
| ✅ **확정** | 결정 완료. 변경하려면 ADR을 새로 작성 |
| ⏸ **의도적 보류** | 지금 정하지 않는 것이 옳다고 판단. 재검토 시점 명시 |
| 🟡 **잠정** | 근거 있는 추천안이나 아직 확정 전 |
| ⬜ **미결** | 후보만 나열됨. 논의 필요 |

## 문서 작성 규칙

- 새 문서는 [_templates](./_templates/)의 템플릿에서 시작합니다
- 모든 문서에 프론트매터(`title` / `aliases` / `tags` / `created` / `updated` / `status`)를 넣습니다
- 링크는 **상대경로 마크다운 링크**를 씁니다 (Obsidian·GitHub 양쪽에서 동작)
- `aliases`에 한글 표기를 넣어 Obsidian 검색·링크가 한글로 되도록 합니다
- 이미지·다이어그램은 [90-첨부](./90-첨부/)에 넣습니다
- 기술 선택이 확정되면 상태 표기를 ✅로 바꾸고, 근거가 큰 결정은 ADR을 추가합니다
- **문서와 코드가 어긋나면 문서가 틀린 것으로 간주**하고 즉시 고칩니다
