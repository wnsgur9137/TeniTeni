# TrackNet

> 연속 3프레임을 입력받아 히트맵을 내는 소형 고속 물체 추적 모델. 테니스·배드민턴 논문의 표준.

**아직 조사하지 않았습니다.** [D-20 서버 ML](../../05-결정/stack/D-20-server-ml.md) 판정 시점 또는 Phase 0 게이트 미달 시 필요해집니다.

## 조사 항목

- 아키텍처와 입력 형식
- 보고된 정확도와 그 조건 (해상도·fps·거리)
- Core ML 변환 가능성
- 우리 온디바이스 결과 대비 개선폭
